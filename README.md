# 🧩 Executive Dashboard Overlay - Chrome Extension

This Chrome extension injects a sleek, executive-style dashboard overlay into webpages. It is designed to showcase high-level performance metrics and a visual trend comparison, ideal for demonstrating the impact of AI-assisted collections over traditional methods.

---

## 🚀 Features

- Beautiful dashboard overlay injected into webpages
- Displays key metrics:
  - ✅ Total Collections
  - ✅ Recovery Rate
  - ✅ Avg Resolution Time
  - ✅ Customer Satisfaction
- Visual bar chart comparison of AI-assisted vs. traditional collections
- Close button to dismiss the dashboard easily
